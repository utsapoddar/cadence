# Cadence

Evidence-backed therapeutic tones. Only frequencies with published peer-reviewed support. Every card cites its source.

## Run locally

Open `index.html` in any modern browser, or:

    python3 -m http.server 8000

then visit http://localhost:8000

## Evidence policy

See `docs/superpowers/specs/2026-04-18-cadence-design.md`. Excluded by design: solfeggio, chakras, Schumann-resonance therapy claims, un-phase-locked pink noise for sleep.
